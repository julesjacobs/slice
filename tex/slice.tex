\section*{Data-Availability Statement}
An anonymized artifact for this paper is available. It contains our OCaml implementation of \Slice{}, all case studies and benchmarks used in the evaluation, the scripts needed to run the experiments, and a Docker image for reproducing the results. The artifact also includes \Dice{}, \Roulette{}, and \Storm{} backends used in our evaluation, together with the translation procedures from discretized programs to each backend. All reported experiments were executed within this Docker environment on an Apple M3 machine with 16\,GB of RAM. We intend to submit the artifact for Artifact Evaluation. The current artifact is a research prototype, but it contains the code, benchmarks, and infrastructure needed to reproduce all experimental results reported in the paper.
