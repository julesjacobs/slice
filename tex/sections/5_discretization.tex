In this section, we describe our type-directed discretization algorithm alongside illustrative examples. The setting is the following: Given a typed expression $e : \tau$ compute --- guided by the type annotations --- a (partially) \emph{discretized} expression $\discretize{e : \tau}$ such that $e$ and $\discretize{e : \tau}$ are \emph{semantically equivalent}, i.e., they produce the same distribution.

$\discretize{e : \tau}$ is defined recursively on $e : \tau$ as shown in \Cref{fig:discretization-code}, where we focus on continuous uniform distributions. For other distributions, this procedure is completely analogous. Naturally, the only sub-expressions which are actually replaced by $\discretize{\cdot}$ are float constants and uniform samplings. Before we go into the details, let us get some intuition on how we use the type annotation to discretize expressions. The type system is designed in such a way that every typed sub-expression of the form 
$e = \uniform(e_1, e_2 )$ of type $\float[B;V]$ with $B=\{\sim_1\!\!b_1, \ldots, \sim_n\!\!b_n\} \neq \top$ 
%
can be \emph{discretized} to an expression $e' : \fin{n+1}$ such that 
%
the probability that $e$ evaluates to a value in $\intervals{B}_i$ \emph{coincides} with the probability that $e'$ evaluates to $\finconst{i}{n+1}$. %Moreover, this information is \emph{all we need} to ensure semantic equivalence of the continuous and the (partially) discretized expression. 
In particular, if \emph{all} $\float[B;V]$-typed subexpressions are finite-cut, then the given expression can be \emph{fully discretized}.  Let us start with simple examples before considering more intricate ones.
%

\begin{example}
	\label{ex:discretize_simple}
The simplest setting is a uniform distribution whose outcomes are compared to constants. Consider the following typed expression $e: \bool$, where we omit irrelevant types:
	%
%
%
\begin{align*}
	&\letkw\; x = (\uniform(0, 1) : \text{\ftn{$B$}})\; \inkw\; \\
	&(x : \text{\ftn{$B$}} < 0.3 : \text{\ftbn{$B$}{$\{0.3\}$}}) \logor (x : \text{\ftn{$B$}} \geq 0.5 : \text{\ftbn{$B$}{$\{0.5\}$}})
\end{align*}
%
where $B= \{ \clt{0.3},\clt{0.5} \}$. Now, why and how can we discretized this program using the type information? The cut set $B$ correctly informs us that the probability of the comparisons evaluating to $\true$ is completely determined by the probability of $x$ evaluating to one of the intervals 
%
\[
	\intervals{B}_0 = (-\infty, 0.3) 
	\qquad 
	\intervals{B}_1 =[0.3, 0.5) 
	\qquad 
	\intervals{B}_2 =[0.5, \infty)
\]
%
induced by $B$. Hence, all expressions of type $\text{\ftbn{$B$}{$\ldots$}}$ can be discretized to expressions of the finite type $\fin{3}$, where $\finconst{k}{3}$ represents the $k$-th interval $\intervals{B}_k$ induced by $B$ for $k \in \{0,1,2\}$. 

Now consider the discretized expression obtained from computing $\discretize{e: \bool}$ given by 
%
\[
	\letkw\; x = \discrete(0.3, 0.2, 0.5)\; \inkw\; 
	(x \finlt{3} \finconst{1}{3})  \logor x \fingeq{3} \finconst{2}{3})~.
\]
%
The probabilities appearing in $\discrete(\ldots)$ are determined by the cumulative distribution function (CDF) of the uniform distribution over $[0,1]$, indeed ensuring that the probability of $x$ evaluating to $\finconst{k}{3}$ in $\discretize{e: \bool}$ \emph{coincides} with the probability of $x$ evaluating to a value in $\intervals{B}_k$ in $e$. Hence, the constant $0.3$ in $e$ can be replaced by the constant $\finconst{1}{3}$ in $\discretize{e: \bool}$, and the constant $0.5$ in $e$ replaced by the constant $\finconst{2}{3}$ in $\discretize{e: \bool}$, and it is evident that $e$ and $\discretize{e: \bool}$ are semantically equivalent. 
\end{example}
%
Crucially, the \emph{answers} constraint in the premise of the typing rules for comparisons (cf.\ \Cref{fig:typing-float}) ensures that $B$ is a correct and sufficiently fine-grained partitioning of $\Reals$, i.e., there is an injective function
%
$
	\text{ToInts} \colon \{0.3, 0.5\} \to \intervals{B}
$
%
such that $c$ is an (open) endpoint of $\text{ToInts}(c)$ for all $c \in\{0.3,0.5\}$. Let us now consider the next example.
%
\begin{example}
	If the arguments to a uniform sampling are non-constant, the situation becomes more challenging. Consider the following typed expression $e : \bool$ (again only showing relevant types):
	%
	\begin{align*}
		&\letkw\; x =  (\ifkw \; 
		(\uniform(0, 1) : \text{\ftn{$\{\clt{0.5}\}$}} )
		< (0.5 :\text{\ftbn{$\{\clt{0.5}\}$}{$\{0.5\}$}}) \; \\
		%
		&\phantom{\letkw\; x ={} } \thenkw \; (10 : \text{\ftbn{$\{\cleq{10},\cleq{20}\}$}{$\{10\}$}}) \; 
		\elsekw \; (20 : \text{\ftbn{$\{\cleq{10},\cleq{20}\}$}{$\{20\}$}})) \\
		%
		&\phantom{\letkw\; x ={} } : \text{\ftbn{$\{\cleq{10},\cleq{20}\}$}{$\{10,20\}$}} \\
		&\inkw\; \\
		%
		&(\uniform(0,(x :  \text{\ftbn{$\{\cleq{10},\cleq{20}\}$}{$\{10,20\}$}})) : \text{\ftn{$\{\clt{5}\}$}} ) < (5 :\text{\ftbn{$\{\clt{5}\}$}{$\{5\}$}})~.
	\end{align*}	
	%
	Why can this expression be discretized even though the argument to the second uniform sampling instruction is non-constant? The typing information $(x : \text{\ftbn{$\{\cleq{10},\cleq{20}\}$}{$\{10,20\}$}})$ correctly informs us about the fact that \emph{$x$ can only take the values $10$ and $20$}. Consequently, $x$ (and the $\ifkw$-expression generating it) can be discretized to a finite type $\fin{3}$ such that the probability of the resulting discrete expression evaluating to $\finconst{0}{3}$ (resp.\ $\finconst{1}{3}$) \emph{coincides} with the probability of the continuous expression evaluating to $10$ (resp.\ $20$). Let us (partially) apply $\discretize{e: \bool}$, resulting in:
	%
	\begin{align*}
		&\letkw \; x = \ifkw\; \discrete(0.5,0.5) \finlt{2} \finconst{1}{2} \; \thenkw \; \finconst{0}{3} \; \elsekw \; \finconst{1}{3} \; \inkw \\
		%
		&\qquad \big(\letkw \; v_1' = \discretize{0 : \text{\ftbn{$\{\cleq{0}\}$}{$\{0\}$}}} \; \inkw \\
		&\qquad\quad\; \letkw \; v_2' = \discretize{x : \text{\ftbn{$\{\cleq{10},\cleq{20}\}$}{$\{10,20\}$}}} \; \inkw \\
		%
		&\qquad\quad\; \ifkw\; v_1' \fineq{2} \finconst{0}{2} \; \logand \; v_2' \fineq{3} \finconst{0}{3} \; \thenkw \; \discretize{\uniform(0,10) : \text{\ftn{$\{\clt{5}\}$}}} \\
		%
		&\qquad\quad\; \elsekw \; \discretize{\uniform(0,20) : \text{\ftn{$\{\clt{5}\}$}}} \big) \finlt{2} \discretize{5 : \text{\ftbn{$\{\clt{5}\}$}{$\{5\}$}}}
	\end{align*}	
	%
	The continuous $\uniform(0,x)$-expression is replaced by a case distinction on the discretizations of $\uniform(0,10)$ and $\uniform(0,20)$, where each of these cases is indeed executed with the correct probability $0.5$. Since this reduces the remaining discretization process to discretizing expressions with \emph{constant parameters only}, the remaining steps are completely analogous to Example~\ref{ex:discretize_simple}.
\end{example}
%
Crucially, the \emph{distinguishes} constraints in the \textsc{Continuous}-rules from \Cref{fig:typing-float} ensure that, for finite-cut sampling expressions, it will always be the case that the parameter expressions can take only finitely many values, and that the cut sets are fine-grained enough to recover the values the parameter expressions evaluate to as demonstrated in the preceding example.

A similar intuition applies to discretizable comparisons $e_1 < e_2$, where \emph{both} expressions are non-constant but finite-cut. The \emph{answers} constraints in the rule \textsc{Less} (resp.\ \textsc{Less-Equal}) ensures that at least one of $e_1$ and $e_2$ evaluates to finitely many values only, which enables discretization:
\begin{example}
	Consider the following typed expression ($(e_1 \leq e_2) : \bool$) given by
	%
	\begin{align*}
		&(\ifkw\;\discrete(0.5,0.5) \finlt{2} \finconst{1}{2} \; \thenkw \; 
		(\uniform(0,10) : \text{\ftn{$B$}})
		\; \elsekw \; (2.5 : \text{\ftbn{$B$}{$2.5$}})) \\
		&\leq \\
		&(\ifkw\;\discrete(0.5,0.5) \finlt{2} \finconst{1}{2} \; \thenkw \; 
		(2.5 : \text{\ftbn{$B$}{$2.5$}})
		 \; \elsekw \; 
		 (3.5 : \text{\ftbn{$B$}{$3.5$}})~,
	\end{align*}
	%
	where $B = \{\cleq{2.5}, \cleq{3.5}\}$, and where $e_1 : \text{\ftn{$B$}}$ and $e_2 : \text{\ftbn{$B$}{$2.5,3.5$}}$. Intuitively, $e_1$ samples from a mixture of a uniform and a dirac distribution, whereas $e_2$ samples from a finite distribution. Why can can $e_1 \leq e_2$ be discretized even though neither $e_1$ nor $e_2$ is a constant? The reason is that, as suggested by it's type, $e_2$ can only take finitely many values in $\{2.5,3.5\}$. Let us apply $\discretize{.}$ and see what happens:
	%
	%
	\begin{align*}
		&(\ifkw \; \discrete(0.5,0.5) \finlt{2} \finconst{1}{2} \; \thenkw \; \discrete(0.25,0.1,0.65) \; \elsekw \; \finconst{0}{3})\\
		%
		&\leq \\
		%
		& (\ifkw \; \discrete(0.5,0.5) \finlt{2} \finconst{1}{2} \; \thenkw \;  \finconst{0}{3} \; \elsekw \; \finconst{1}{3})
	\end{align*}
	%
	Notice that the probability of $e_1$ evaluating to some value in $(-\infty, 2.5]$ indeed \emph{coincides} with the probability of $e_1's$ discretization evaluating to $\finconst{0}{3}$. For $e_2$, on the other hand, the probability of it evaluating to $2.5$ (resp.\ $3.5$) \emph{coincides} with the probability of its discretization evaluating to $\finconst{0}{3}$ (resp.\ $\finconst{1}{3}$). It is for this reason that we indeed produce a semantically equivalent discretization of $e_1 \leq e_2$.
\end{example}




\subsection{Discretization of Types}
We conclude this section by extending the discretization function $\discretize{\cdot}$ formally to types. \Cref{fig:discretization-types} shows how type $\tau$ is discretized to type $\discretize{\tau}$. We then obtain the following natural result regarding the transformation of types when applying $\discretize{\cdot}$ to programs:
%
\begin{figure}[t]
	\centering
	\begin{align*}
		\discretize{\tau} &= 
		\begin{cases}
			\fin{n+1}, & \text{if } \tau = \float[B; V] \text{ and } B = \{\sim_1\!\!b_1, \ldots, \sim_n\!\!b_n\} \\[0.5em]
			\float, & \text{if } \tau = \float[B; V] \text{ and } B = \top \\[0.5em]
			\discretize{A} \to \discretize{B}, & \text{if } \tau = A \to B \\[0.5em]
			\discretize{A} \times \discretize{B}, & \text{if } \tau = A \times B \\[0.5em]
			\listty{\discretize{A}}, & \text{if } \tau = \listty{A} \\[0.5em]
			\texttt{ref}(\discretize{A}), & \text{if } \tau = \texttt{ref}(A) \\[0.5em]
			\tau, & \text{otherwise}
		\end{cases}
	\end{align*}
	\caption{Transformation of types under $\mathcal{D}$, where $\mathcal{D}$ acts on types.}
	\label{fig:discretization-types}
\end{figure}
%
%
\begin{lemma}[Discretization Is Well-Typed]\label{lem:type-transformations}
	Let $\Gamma \vdash e : \tau$ be a well-typed expression in \Slice{}, where $\Gamma$ is a typing environment assigning types to variables. Let $\discretize{e : \tau}$ be the discretization function from Figure~\ref{fig:discretization-code}, and $\discretize{\tau}$ be the type transformation function as defined in Figure~\ref{fig:discretization-types}. Then,
	\[
	\discretize{\Gamma} \vdash \discretize{e : \tau} : \discretize{\tau}
	\]
	where $\discretize{\Gamma}$ transforms all types in $\Gamma$, i.e., $\discretize{\Gamma}(x) = \discretize{\Gamma(x)}$ for all $x \in \textnormal{dom}(\Gamma)$.
\end{lemma}
%
\begin{proof}
	See Appendix~\ref{proof:type-transformations}.
\end{proof}
