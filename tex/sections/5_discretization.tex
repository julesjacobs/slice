\section{Discretization}\label{sec:discretization}

After type inference, each float-typed expression carries refinement information in its $\float[B; V]$ type. The discretization transformation uses this information to convert continuous probabilistic programs into discrete ones that can be analyzed exactly. We describe our discretization method in terms of probability spaces. In a general sense, a discretization function takes as input a probability space $(\Omega, \Sigma, \mu)$ and outputs a discrete probability space $(\Omega_D, \Sigma_D, \mu_D)$ where $\mu_D$ is a countable set. Let $\mathbb{R}$ denote the set of all real numbers and $B(\mathbb{R})$ the Borel $\sigma$-algebra of subsets of $\mathbb{R}$. For the output probability space, denote $P(S)$ to refer to the power set of set $S$, a $\sigma$-algebra. We describe how our sample space is discretized:

\begin{definition}[Discretization function for distributions]
    Let $b_1, ...b_n$ be cuts in $B$. Let $S = \intervals{B}$. Let $\pi$ be a continuous distribution with support $[l,r]$. The discretization function takes as input a probability space $(\mathbb{R}, B(\mathbb{R}), \mu)$ and outputs a discrete probability space $(S, P(S), \mu_D)$, where the probability measure $\mu_D$ is defined as: 
    \[
    \Pr[\{S_i\}] =
    \begin{cases}
        \text{cdf}_{\pi}(x_1) - \text{cdf}_{\pi}(\max(-\infty, l)), & \text{ if } i = 1 \\
        \text{cdf}_{\pi}(\min(r, +\infty)) - \text{cdf}_{\pi}(x_n), & \text{ if } i = n+1 \\
        \text{cdf}_{\pi}(x_{i+1}) - \text{cdf}_{\pi}(x_i), & \text{ if otherwise}
    \end{cases}
    \]
\end{definition}

\paragraph{Example.} Let $\pi$ be the uniform distribution on the unit interval $[0,1]$. Take the input probability space to be $(\mathbb{R}, B(\mathbb{R}), \mu)$. Let $B = \{0.5, 0.8, 0.9\}$. Consider the function $d_1$ that takes $\pi$ as input and outputs the probability space $(S, P(S), \mu_D)$ where $S = \{(-\infty, 0.5), [0.5, 0.8), [0.8, +\infty)\}$ and $\mu_D$ is a probability measure on $P(S)$. The probability measure $\mu_D$ is thus: $S_1 = 0.5$, $S_2 = 0.3$, $S_3 = 0.1$, and $S_4 = 0.1$. $d_1$ is thus a valid discretization function for continuous distributions.

The key insight is that if an expression with a float type $\float[B; V]$ is co-discrete, we can partition $\mathbb{R}$ into intervals separated by the cuts $\clt{x_1}, ..., \clt{x_n} \in B$ to obtain $\intervals{B}$, giving the finite type $\fin{n+1}$ where $n$ is the number of cuts, where $\finconst{0}{n+1}$ is mapped to $(-\infty, x_1)$, $\finconst{1}{n+1}$ is mapped to $(x_1, x_2)$, and so on until $\finconst{n}{n+1}$ is mapped to $(x_n, +\infty)$. Then, depending on $V$: 

\begin{itemize}
    \item if $V = \top$: Each value in $\fin{n+1}$ occurs with the probability mass of the original continuous distribution within the corresponding interval. This gives a $\discrete(p_0, \ldots, p_{n})$ distribution, which returns a finite type value $\finconst{k}{n+1}$ with probability $p_k$.
    
    \item if $V = \{c_1, ..., c_n\}$: Each float constant $c \in {c_1, ..., c_n}$ is assigned an integer index $k$ corresponding to the interval in $\intervals{B}$ that contains $c$. For each $c$, the finite type value $\finconst{k}{n+1}$ is returned.
\end{itemize}


If an expression with a float type is co-continuous, proper discretization cannot be performed for that expression and as a result \Slice{} preserves its original semantics.

\subsection{Discretization Rules}

The transformation $\texttt{discretize}(e)$ is defined recursively on the structure of typed expressions. We first define the types of expressions $\texttt{discretize}(e)$ produces, which is either a fully discretized or a partially discretized program. A fully discretized program contains only discrete distributions.

\begin{definition} [Full discretization]\label{def:full-discr}
    A program can be \textit{fully discretized} by \Slice{} if all its expressions are either discrete (in the trivial case) and/or co-discrete.
\end{definition}

\begin{definition} [Partial discretization]\label{def:partial-discr}
    A program can only be \textit{partially discretized} by \Slice{} if there exist any co-continuous expressions.
\end{definition}

\subsection{Algorithm for Discretization}
\katherine{to do}


\paragraph{Float Constants} For a constant $c$ with type $\float[B; V]$:
\begin{itemize}
    \item If $B = \top$: remains as constant $c$
    \item If $B = \{b_1, \ldots, b_n\}$: becomes $\finconst{k}{n+1}$ where $k$ is the index of the interval containing $c$
\end{itemize}

\paragraph{Continuous Distributions} For a distribution $d$ with type $\float[B; V]$ where $B = \{b_1, \ldots, b_n\}$:
\begin{enumerate}
    \item Extract numeric thresholds $c_1 < \cdots < c_n$ from cuts in $B$
    \item Let $\text{CDF}_d(b_i)$ be the measure of the distribution $d$ on the interval $(-\infty, c_i)$ if $b_i =\ <\!\!c_i$ and on the interval $(-\infty, c_i]$ if $b_i =\ \leq\!\!c_i$. Take $\text{CDF}_d(b_{0}) = 0$ and $\text{CDF}_d(b_{n+1}) = 1$.
    \item Calculate probability mass for each interval using the CDF:
    \[ p_i = \text{CDF}_d(b_i) - \text{CDF}_d(b_{i-1}) \]
    \item Generate $\discrete(p_1, \ldots, p_{n+1})$ returning interval indices.
\end{enumerate}

If $B = \top$, the distribution remains continuous.

\paragraph{Comparisons} For $e_1 < e_2$ where both have type $\float[B; V]$:
\begin{itemize}
    \item If $B = \top$: comparison remains as $\texttt{discretize}(e_1) < \texttt{discretize}(e_2)$
    \item If $B = \{b_1, \ldots, b_n\}$: becomes $\texttt{discretize}(e_1) \finlt{n+1} \texttt{discretize}(e_2)$ (or, $\leq$ becomes $\finleq{n+1}$)
\end{itemize}

The finite comparison $\finlt{n+1}$ operates on interval indices.

\paragraph{Structural Constructs} All other constructs are discretized recursively:
\begin{itemize}
    \item Variables pass through unchanged, though their type may change
    \item Let bindings, conditionals, pairs, etc., recursively discretize subexpressions
\end{itemize}

\paragraph{Effect of discretization on types} The types change as follows:
\begin{itemize}
    \item $\texttt{discretize}(\float[B; V]) = \fin(n+1)$ if $B = \{b_1, \ldots, b_n\}$
    \item $\texttt{discretize}(\float[B; V]) = \float$ if $B = \top$
    \item $\texttt{discretize}(A \to B) = \texttt{discretize}(A) \to \texttt{discretize}(B)$
    \item $\texttt{discretize}(A \times B) = \texttt{discretize}(A) \times \texttt{discretize}(B)$
    \item $\texttt{discretize}(\listty{A}) = \listty{\texttt{discretize}(A)}$
    \item $\texttt{discretize}(\texttt{ref}(A)) = \texttt{ref}(\texttt{discretize}(A))$
    \item Other types remain unchanged.
\end{itemize}


\subsection{Example}

Consider the following program:
\begin{lstlisting}
let x = uniform(0.0, 1.0) in
if x < 0.5 then 
  if x < 0.7 then 1 else 2
else 3
\end{lstlisting}

After type inference, \texttt{x} has type $\float[\{<0.5, <0.7\}; \top]$. Discretization:
\begin{enumerate}
    \item Extracts thresholds: $\{0.5, 0.7\}$
    \item Creates intervals: $I_0 = (-\infty, 0.5)$, $I_1 = [0.5, 0.7)$, $I_2 = [0.7, \infty)$
    \item Calculates probabilities: $p_0 = 0.5$, $p_1 = 0.2$, $p_2 = 0.3$
    \item Generates: \texttt{let x = discrete(0.5, 0.2, 0.3) in ...}
    \item Transforms comparisons: \texttt{x < 0.5} becomes \texttt{x}$\finlt{3}$\texttt{1}, \texttt{x < 0.7} becomes \texttt{x}$\finlt{3}$\texttt{2}
\end{enumerate}

The discretized program preserves the original semantics while enabling exact inference.

\subsection{Variable Distribution Parameters}

A key challenge arises when distribution parameters are not constant.
For variable distribution parameters, we use the value set $V$ in $\float[B; V]$ to reconstruct the appropriate distribution to compute the CDF on.
Due to the typing rules, each interval induced by $B$ can contain at most one value from $V$. This means that we can uniquely reconstruct the original floating point number from the interval index, by a series of conditionals.
The distribution can then be discretized as if its parameters were constant in each branch of the conditionals.

Consider the following program:
\begin{lstlisting}
let scale = discrete(0.5, 0.5) in
let x = if scale = 0 then exponential(1.0) 
        else exponential(2.0) in
x < 3.0
\end{lstlisting}

During type inference, the parameter to \texttt{exponential} has type $\float[B_{\text{param}}; \{1.0, 2.0\}]$. The implementation generates runtime dispatch code that:
\begin{enumerate}
    \item Evaluates the parameter expression
    \item Matches against possible constant values from the value set
    \item Applies appropriate discretization for each case
\end{enumerate}

This ensures correct discretization even when distribution parameters depend on runtime values.
