\section{Evaluation}\label{sec:implem_eval}

We use experiments to characterize the empirical consequences of exact discretization, emphasizing asymptotic scaling as program size grows. We evaluate \Slice{}+\Dice{} and \Slice{}+\Roulette{} on (i) constructed scaling benchmarks and (ii) benchmark suites from prior literature, and report results with \SPPL{}. These systems are complementary exact-inference pathways: \SPPL{} performs direct symbolic exact inference over its supported fragment (including numeric transformations and conditioning on measure-zero events), while \Slice{} applies an exact source-to-source transformation to a discrete form solved by discrete backends.

The \Slice{} compiler consists of approximately 3,400 lines of OCaml code (including the lexer, parser, type inference and discretization engines, and \Dice{}/\Roulette{} code generators). We use the OCaml GSL package~\cite{gsl} to compute the CDFs of the probability distributions. The system is open-source and available at \url{https://github.com/[anonymized]}, along with benchmarks, documentation, and a Docker image. All benchmarks were run within that Docker image on an Apple M3 with 16GB RAM.

\subsubsection{New Benchmarks for Scaling}\label{sec:synthetic-benchmarks} We designed scalable benchmarks of conditionally independent continuous programs with varying variable dependencies. Formally, all programs in our benchmark can be described by the conditional independence structure: $X_i \perp\!\!\!\perp \{\,X_j : j < i, j \neq \pi(i)\,\}
\;\Big|\; X_{\pi(i)}$, where $\pi(i) \in \{1, \ldots, i-1\}$ is the parent index of $X_i$. Schematically:
%
    \begin{lstlisting}[aboveskip=0.1em,belowskip=.1em]
        let x1 = uniform(0,1) in 
        let x2 = if x1 < r1 then uniform(0,2) else uniform(0,3) in 
        let x3 = if x2 < r2 ...
        ...
        x_n < 0.5
    \end{lstlisting}
%
 Each program consists of a sequence of conditionals, where each branch depends on a previous variable sampled from a uniform distribution, proceeding until the final condition $x_n < 0.5$ is reached. Here $0 \leq r_i \leq 1$ are fixed float constants. Results are depicted in \Cref{fig:alt-benchmarks-main}. Detailed listings and graphs for variants of these benchmarks appear in the supplemental Appendix~\ref{appen:synthetic-sketches}.

 We report runtime (seconds) for (i) \SPPL{}, (ii) \Slice{} (discretization only), (iii) \Slice{}+\Dice{} (discretization plus inference via \Dice{}), and (iv) \Slice{}+\Roulette{} (discretization plus inference via \Roulette{}). We use a timeout of 120 seconds. Program sizes are evaluated in increments of 5, from 0 to 50. For each size, we generate multiple random instances and report average runtime.\jules{Verify exact run count used for the plotted scaling results; the current scripts default to 10 unless overridden.} The key empirical signal is asymptotic: discretization remains small across sizes, while end-to-end runtimes for \Slice{} with discrete backends grow more mildly on these families; direct symbolic inference reaches a clear timeout frontier at larger instances (cf.\ \Cref{fig:alt-benchmarks-main}).

\subsection{Unbounded Recursion}\label{sec:examples:7}

We now consider a program with recursion, where control flow may revisit the same expression an unbounded number of times. Such programs are common in probabilistic modeling (e.g., geometric processes), but are challenging for sampling-based methods, which may fail to terminate due to self-loops.

\begin{lstlisting}[aboveskip=1em,belowskip=1em]
    (fix geom x := 
        if x <= 0.5 then true
        else if x <= 0.8 then geom x
        else let y = uniform(0,1) in geom y) 1
\end{lstlisting}

\noindent This program repeatedly evaluates \texttt{geom}, potentially recursing indefinitely when $x \in (0.5, 0.8]$. In the final branch, a fresh sample is drawn and the process continues. While the recursion is unbounded, the key insight is that the observable behavior of the program depends only on which interval the current value of $x$ lies in.

\noindent As in previous examples, \Slice{} extracts the relevant cut set from the comparisons against $0.5$ and $0.8$. These cuts partition the real line into three intervals:
\[
(-\infty, 0.5], \quad (0.5, 0.8], \quad (0.8, +\infty).
\]

\noindent The resulting discretized program is:

\begin{lstlisting}[aboveskip=1em,belowskip=1em]
    (fix geom x := 
        if x <= 0 then true
        else if x <= 1 then geom x
        else let y = discrete(0.5, 0.3, 0.2) in geom y) 2
\end{lstlisting}

\noindent Crucially, the resulting program has a finite state space. This enables exact reasoning via finite-state methods such as Markov chain analysis via Storm.
