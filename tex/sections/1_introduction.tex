Probabilistic programming languages (PPLs) have emerged as a powerful tool for building complex statistical models and reasoning about uncertainty~\cite{Moy2025Roulette,Holtzen2020Dice,DeRaedt2007ProbLog,Saad2021SPPL,Carpenter2017Stan,Salvatier2016PyMC3,Bingham2019Pyro,Dillon2017TFP,Tran2016Edward,Tolpin2016Anglican,Goodman2014WebPPL,Pfeffer2009Figaro,Minka2018InferNET,Ge2018Turing,CusumanoTowner2019Gen,Tehrani2020BeanMachine,Goodman2008Church}. In particular, continuous PPLs are useful in representing rich stochastic processes where expressiveness is essential. However, continuous PPLs pose challenges for the analysis, inference, and verification of programs, as their semantics often involve reasoning over uncountable domains or integrals over high-dimensional spaces. Discrete PPLs, on the other hand, are easier to reason about, but their limited expressiveness makes it difficult to naturally model phenomena that inherently involve real-valued quantities.

We introduce \Slice{}, a language and compiler that automatically translates continuous distributions in a hybrid program to discrete distributions. The resulting program is a fully discrete probabilistic program, allowing one to leverage the well-understood semantics, analysis techniques, and execution strategies developed for discrete languages, while preserving the semantics of the original continuous model. Specifically, \Slice{} uses a type system to track all the constant thresholds against which continuous variables are compared. These cuts are then used to discretize the continuous distributions into a finite number of intervals. This type-directed discretization enables developers to express rich continuous models while retaining the tractability and formal clarity of discrete programs.

We note that the idea of discretization in probabilistic programming is not new in the literature. Most notably, Garg et. al. introduced bit blasting for hybrid probabilistic programs~\cite{Garg2024BitBlast}. Even though their discretization is sound for a certain class of common continuous densities, in which they term mixed-gamma distributions, the granularity of their intervals is driven by an external precision parameter $b$, where as ours is driven by program structure (e.g. the number of intervals arises from the set of constant thresholds the program uses). Moreover, Slice broadens the interoperability and reuse of existing discrete PPLs, as it produces a discrete PPL instance amentable to any discrete engine without altering semantics. Additionally, Huang et. al. give an inference algorithm for probabilistic programs with continuous posteriors that approximates the program via quantization~\cite{Huang2021AQUA}.

Also closely related is the work of \citet{Holtzen2018Abstraction} who use abstract interpretation to translate a hybrid discrete-continuous program into a finite Boolean program.
Their approach is distributionally sound, but it relies on the user to provide a set of predicates to abstract the program with.
In contrast, our work automatically infers discretization points from the program itself.

We introduce a new approach to discretization that we call \emph{exact discretization}. For instance, our type system transforms \uniform(0, 1) < 0.5 to \discrete(0.5, 0.5) < 1, where the continuous uniform distribution becomes a discrete choice with two equally likely outcomes.

The true power of our approach, however, lies in its ability to handle programs where these relationships are not immediately obvious. A single continuous variable might be compared against multiple different constants across separate parts of the program. Further, these constraints are propagated through complex control flow. For example, a value drawn from a continuous distribution might be returned from one branch of a conditional, passed through a higher-order function, or stored in a data structure before it is eventually compared to a constant. \Slice{}'s type inference systematically tracks these dependencies, ensuring that all relevant cuts are associated with the original distribution, regardless of how the value flows through the program. This robust, whole-program analysis is the key to handling expressive models, as we demonstrate in \Cref{sec:examples}.

Our approach has important limitations: only programs where continuous variables are compared against constants can be fully discretized. Programs that compare continuous variables directly to each other cannot be fully discretized. 

\Slice{}  scales to complex programs and language features. The \Slice{} language itself is a statically-typed functional language that supports a rich set of features, including higher-order functions, recursion, pairs, lists, and mutable references. Our transformation handles these features, allowing programmers to write expressive, high-level models that can still be analyzed with discrete PPLs, provided that continuous variables are only compared to constants. 

\smallskip
\noindent\textbf{Backend Flexibility.} \Slice{}'s discretization is backend-agnostic: any discrete PPL that supports finite distributions can serve as a target. We demonstrate the practicality of our approach on the problem of exact inference for continuous programs. By integrating our approach with two backends \Dice{} and \Roulette{}, we show that \Dice{} provides good performance for first-order programs, achieving speedups of up to 90x compared to SPPL. However, Dice cannot handle higher-order functions or recursion. Roulette~\cite{Moy2025Roulette} supports these advanced features, enabling \Slice{} to perform exact inference on higher-order continuous programs. This flexibility allows users to choose the right backend for their specific modeling needs, and future discrete PPLs can also serve as compilation targets. 

\smallskip
\noindent\textbf{Contributions.} After introducing \Slice{} by example (\Cref{sec:examples}), we present and evaluate our framework for type-directed discretization via the following contributions:
\begin{description}[leftmargin=0.3cm,topsep=3pt]
    \item[Type System (\Cref{sec:language})] We introduce a novel type system that identifies which expressions are discretizable by analyzing how they are compared against constant values throughout the program.

    \item[Type Inference (\Cref{sec:type-inference})] We develop a type inference algorithm that automatically collects the set of constant thresholds needed for discretization for each expression.

    \item[Discretization (\Cref{sec:discretization})] We present a type-directed program transformation that soundly converts continuous distributions and their comparisons into discrete counterparts.

    \item[Soundness (\Cref{sec:soundness})] We prove that our discretization method is sound, establishing that discretization preserves the semantics of the original program. Our proof employs probabilistic couplings, a technique for reasoning about program equivalences in probabilistic languages~\cite{Bizjak2015Step,Wand2018Contextual}.

    \item[Implementation and Evaluation (\Cref{sec:implem_eval})] We provide an open-source implementation of \Slice{} that compiles programs for the Dice and Roulette exact inference engines (\Cref{fig:architecture}). We conduct an empirical evaluation on a range of benchmarks, old and new, demonstrating that our approach is faster than prior symbolic techniques on hybrid programs while maintaining correctness.
\end{description}
