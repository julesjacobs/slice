\begin{abstract}
Probabilistic programming languages (PPLs) enable statistical modeling, but exact inference with continuous variables remains challenging—discrete PPLs are fast but limited to finite models while continuous PPLs typically rely on approximation or slower exact inference. This paper introduces \Slice{}, a language and compiler that automatically transforms continuous probabilistic programs into equivalent discrete ones. Our novel type system statically analyzes where continuous variables are compared to constants, determining cuts that partition continuous domains into intervals. \Slice{} replaces continuous distributions with discrete distributions over these intervals, enabling exact inference via existing discrete PPL engines. The approach is limited to programs comparing continuous variables against constants; comparisons between continuous variables prevent full discretization. We formalize the transformation, prove soundness, and provide an open-source implementation. Evaluation shows our approach is significantly faster than symbolic inference for hybrid programs while maintaining exactness.
\end{abstract}
