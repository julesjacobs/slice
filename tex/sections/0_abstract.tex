\begin{abstract}
We study \emph{exact discretization} as a semantics-preserving transformation for recursive, higher-order probabilistic programs with continuous distributions. We target programs where continuous values are compared against finitely many constants, so exact inference reduces to a discrete problem. Our central technical contribution is a non-local, type-directed analysis that infers where continuous values can be partitioned into finitely many observationally relevant regions, then rewrites sampling and comparison behavior over those regions. We call this transformation \Slice{}. Because this construction is global and type-directed, correctness requires reasoning beyond the local syntax: we formalize the transformation and prove soundness for boolean queries using a coupling-style logical relations argument over operational semantics. As an application, transformed programs can be executed by discrete engines such as \Dice{}, \Roulette{}, and \Storm{}. The mathematical transformation uses exact real interval masses; our prototype approximates these masses with floating-point CDF calculations, after which a discrete backend can reason exactly only relative to the resulting numerical weights. Our empirical evaluation shows that this implementation handles case studies combining continuous sampling, higher-order functions, and unbounded recursion and, on benchmarks where direct comparison is possible, is competitive with exact inference systems for continuous programs.
\end{abstract}
