\begin{abstract}
We study \emph{exact discretization} as the intended specification of a transformation for recursive, higher-order probabilistic programs with continuous distributions. We target programs where continuous values are compared against finitely many constants, so the transformation reduces inference to a discrete problem. Our central technical contribution is a non-local, type-directed analysis that infers where continuous values can be partitioned into finitely many observationally relevant regions, then rewrites sampling and comparison behavior over those regions. We call this transformation \Slice{}. Because this construction is global and type-directed, correctness requires reasoning beyond the local syntax: we formalize the transformation and its operational semantics, and state the measurable weak compiler simulation and terminal-limit compatibility needed for soundness of boolean queries. These proof obligations remain open. Transformed programs can be executed by discrete engines such as \Dice{}, \Roulette{}, and \Storm{}. Our empirical evaluation shows that \Slice{} supports case studies combining continuous sampling, higher-order functions, and unbounded recursion and, on benchmarks where direct comparison is possible, is competitive with exact inference systems for continuous programs.
\end{abstract}
