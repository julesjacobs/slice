\begin{abstract}
%Continuous probabilistic programming languages offer the expressiveness required to model complex stochastic processes and uncertainty, but they are challenging to analyze and execute. 
We present \Slice{}, a language and compiler that analyzes whether higher-order continuous probabilistic programs are discretizable, and transforms these into semantically equivalent discrete ones. Our novel type system statically analyzes where continuous variables are compared to constants, determining cuts that partition continuous domains into intervals. \Slice{} replaces continuous distributions with discrete distributions over these intervals. We formalize this source-to-source program transformation and prove its soundness using a technique akin to probabilistic couplings. As an application, discretization enables exact inference on continuous programs using discrete inference backends like \Dice{} and \Roulette{}, resulting in speedups of up to 80$\times$ on existing benchmarks and orders-of-magnitude improvements on new ones when compared to \SPPL{}, a state-of-the-art exact inference engine for hybrid probabilistic programs.
\end{abstract}
