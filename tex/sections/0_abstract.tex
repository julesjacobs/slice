\begin{abstract}
We study \emph{exact discretization}, an intended semantics-preserving transformation for recursive, higher-order probabilistic programs with continuous distributions. We target programs where continuous values are compared against finitely many constants, so inference reduces to a discrete problem. Our central technical contribution is a non-local, type-directed analysis that infers where continuous values can be partitioned into finitely many observationally relevant regions, then rewrites sampling and comparison behavior over those regions. We call this transformation \Slice{}. Correctness requires reasoning beyond the local syntax: we formalize the transformation and develop a coupling-style logical relation over operational semantics. The full semantic-preservation result remains conditional on an open weak-simulation obligation. The mathematical construction uses exact real interval masses; our prototype instead computes and normalizes floating-point CDF approximations, which discrete backends analyze as a numerical model. Our empirical evaluation shows that this implementation handles case studies combining continuous sampling, higher-order functions, and unbounded recursion and, on benchmarks where direct comparison is possible, is competitive with exact inference systems for continuous programs.
\end{abstract}
