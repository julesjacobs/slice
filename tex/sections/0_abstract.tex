\begin{abstract}
Probabilistic programming languages (PPLs) enable statistical modeling, but exact inference with continuous variables remains challenging—discrete PPLs are fast but limited to finite models, while continuous PPLs typically rely on approximation or slower exact inference. This paper introduces \Slice{}, a language and compiler that automatically transforms continuous probabilistic programs into equivalent discrete ones. Our novel type system statically analyzes where continuous variables are compared to constants, determining cuts that partition continuous domains into intervals. \Slice{} replaces continuous distributions with discrete distributions over these intervals, enabling exact inference via existing discrete PPL engines. For full discretization of a continuous program, our approach is limited to programs comparing continuous variables against constants; however, for more general programs, partial discretization is possible. We formalize the transformation and provide an open-source implementation that can target multiple discrete inference backends. We demonstrate our approach with two backends: Dice for maximum performance on first-order programs, yielding significant speedups (up to 200×) over
symbolic inference for hybrid programs, and Roulette for programs requiring higher-order functions or mutable state, uniquely enables exact inference for continuous probabilistic programs with these advanced features—a capability no existing system provides.
\end{abstract}
