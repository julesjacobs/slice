 The first step is to make formal sense of semantic equivalence. For that, we will define a monadic operational semantics for our language. We will then proceed by proving the above claim. This is non-trivial:  Discretization decisions are driven by non-local, type-propagated information, so that we cannot proceed by a local rule-by-rule argument. \subsection{Operational Semantics}
%
The type-directedness of our discretization function $\discretize{\cdot}$ requires our soundness argument to depend on the types of the given (sub-)expressions as well. We thus start by defining a \emph{type-dependent semantic functional}, i.e., we define for every type $\tau$ a function
%
\[
	\bigsem{\cdot}\colon Expr_\tau \to \mathcal{D}(Vals_\tau + \bot)~,
\]
%
mapping each expression $e:\tau$ to a (possibly continuous) \emph{sub}-probability measure $\bigsem{e : \tau}$ over values of type $\tau$ or $\bot$. In the presence of possibly unbounded recursion \emph{and} conditioning, our semantics has to distinguish between non-termination and observation failure, which we realize as follows: The \enquote{missing} probability mass in $\bigsem{e : \tau}$ ist the probability that $e$ diverges. The probability of $\bot$ is the probability of encountering an observation failure. With this model, semantic equivalence indeed captures our sought-after correctness claim: If $\bigsem{e:\bool} = \bigsem{\discretize{e:\bool}:\bool}$, then both expressions have the same probability of producing $\true$, $\false$, or an observation failure.

Defining the latter requires to carefully design a suitable measurable space over the set of expressions of type $\tau$ and $\bot$. We start by defining a small-step operational functional $\sem{\cdot}\colon Expr_\tau \to\mathcal{D}(Expr_\tau + \bot)$ (cf.\ \Cref{tab:smallstep-1} on page \pageref{tab:smallstep-1}), mapping each expression $e$ of type $\tau$ to a (possibly continuous) subdistribution $\sem{e:\tau}$ over expressions of type $\tau$ or $\bot$. The missing probability mass corresponds to the probability of encountering an error due to ill-defined invocations of sampling instructions (e.g., $\uniform(1,0)$). The probability of $\bot$ is the probability of observation failure. 

Using this small-step operational functional, we employ a limit construction to define a (big-step) functional $\bigsem{\cdot}\colon Expr_\tau \to \mathcal{D}(Vals_\tau + \bot)$, mapping each expression $e$ of type $\tau$ to a subdistribution $\bigsem{e:\tau}$ over \emph{values} of type $\tau$ or $\bot$. The missing probability mass now \emph{additionally} captures $e$'s non-termination probability, and the probability of $\bot$ is the probability of observation failure. 

\subsection{Soundness via Probabilistic Couplings}
%
We first state the central theorem, then outline the coupling-style relational argument used in its proof.
%
\begin{theorem}
	\label{thm:maintext:sound}
	Let $e:\bool$. Then $\bigsem{e:\bool} = \bigsem{\discretize{e:bool} : \bool}$.
\end{theorem}
%
Intuitively, we prove that the two programs can execute in a synchronized manner such that their probabilities of terminating in value $v$ coincide for each $v \in \{\true,\false,\bot\}$. Because sub-expressions may have types other than $\bool$, the argument must (i) apply to expressions of \emph{arbitrary} type and (ii) be strong enough to imply \Cref{thm:maintext:sound}.
%e, and which lets us conclude semantic equivalence for expressions of type $\bool$.
%more general argument which enables us to conclude semantic equivalence.% The crucial point is when we encounter a continuous sampling instruction in $e$, in which case we have to prove that its discretized counterpart $\discretize{e:\tau}$

Towards this end, define for every type $\tau$ the set $P_\tau = \{ (e:\tau, \discretize{e : \tau} : \discretize{\tau}) ~|~ e:\tau \}$. We define a \emph{coupled small-step semantics} $\sem{\cdot,\cdot} \colon P_\tau \to \mathcal{D}(P_\tau + \bot)$ (cf.\ \Cref{tab:coupling_smallstep_1,tab:coupling_smallstep_2}), which models the simultaneous execution of $e$ and $\discretize{e:\tau}$. The key property of this coupled semantics is that the semantics of both $e$ and $\discretize{e:\tau}$ can be recovered in a sense we formalize next.

Given $\mu \in \mathcal{D}(P_\tau + \bot)$, we define the \emph{projection of $\mu$ onto the $i$-th component} for $i\in\{ 1,2 \}$ as
%
\[
	\pi_i(\mu) = \lambda A. \int_{x \in P_\tau + \bot} 
	\begin{cases}
		 \delta_{e_i}(A) & x = (e_1,e_2)  \\
		 %
		 \delta_\bot(A)  & x = \bot
	\end{cases}
	%
	\mu(dx)~,
\]
%
where $\delta_a$ denotes the Dirac distribution of $a$. We recover the semantics of $e$ and $\discretize{e:\tau}$ as follows:
\begin{lemma}
	\label{lem:maintext:small_step_coupling_props}
	Let $e:\tau$. We have:
	%
	\begin{enumerate}
		\item\label{lem:maintext:small_step_coupling_props1} 
		$\pi_1(\sem{e:\tau, \discretize{e : \tau} : \discretize{\tau}}) = \sem{e:\tau}$.
		%
		\item\label{lem:maintext:small_step_coupling_props2} 
		$\pi_2(\sem{e:\tau, \discretize{e : \tau} : \discretize{\tau}}) = \sem{\discretize{e : \tau}:\discretize{\tau}}$.
	\end{enumerate}
\end{lemma}

Now, using a limit construction to obtain a coupled \emph{big-step} semantics $\bigsem{\cdot,\cdot} \colon Expr_\tau \to \mathcal{D}(V_\tau + \bot)$, where $V_\tau = \{ (v:\tau, \discretize{v} : \discretize{\tau}) ~|~ v:\tau~\text{is a value} \}$, it is easy to prove that Lemma \ref{lem:maintext:small_step_coupling_props} also holds for $\bigsem{\cdot,\cdot}$. Finally observing that $V_\bool + \bot = \{(\true,\true), (\false,\false), \bot\}$ yields the desired claim:

%\noindent
\emph{Proof of \Cref{thm:maintext:sound}}. Let $v \in \{\true,\false,\bot\}$. We have
%
\begin{align*}
	& \bigsem{e : \bool}(v) \\
	%
	{}={}~& \pi_1(\bigsem{e:\bool, \discretize{e : \bool} : {\bool}})(v)
	\tag{Lemma \ref{lem:maintext:small_step_coupling_props}.\ref{lem:maintext:small_step_coupling_props1} for $\bigsem{\cdot,\cdot}$} \\
	%
    {}={}~& \pi_1(\bigsem{e:\bool, \discretize{e : \bool} : {\bool}})(v)
    \tag{$P_\bool$ is discrete} \\
    %
    {}={} & \bigsem{e : \bool, \discretize{e : \bool}:{\bool}}((\true,\true))\cdot \delta_{\true}(v) \\
    &{}+ 
    \bigsem{e : \bool, \discretize{e : \bool}:{\bool}}((\false,\false))\cdot \delta_{\false}(v) \\
    &{}+ 
    \bigsem{e : \bool, \discretize{e : \bool}:{\bool}}(\bot)\cdot \delta_{\bot}(v) 
    \tag{definition of $\pi_1$, argument is discrete} \\
    %
    {}={}~& \pi_2(\bigsem{e:\bool, \discretize{e : \bool} : {\bool}})(v)
    \tag{definition of $\pi_2$, argument is discrete} \\
    %
    {}={}~& \bigsem{\discretize{e : \bool}:{\bool}}(v)~.
    \tag{Lemma \ref{lem:maintext:small_step_coupling_props}.\ref{lem:maintext:small_step_coupling_props2} for $\bigsem{\cdot,\cdot}$}
\end{align*}
